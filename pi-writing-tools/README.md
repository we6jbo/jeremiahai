# JeremiahAI Writing Tools

This directory is intended for Mistral Vibe writing support on the Ladybug Pi.

Paths:
- `/home/jeremiahai/writing-tools/` — lightweight helper tools only
- `/home/jeremiahai/writing-draft/` — temporary/working ideas, outlines, expansion notes, and sanitized Moltbook questions

Rules:
- Protect port 80 and port 8080.
- Keep Pi disk usage below 50%.
- Do not install broad packages just for writing support.
- Before anything is posted publicly to Moltbook, run `privacy_check.py`.
- If the privacy gate does not print PASS, do not publish.
- Public Moltbook questions must use only sanitized text.
- Treat PH-A, PH-B, PH-C, and PH-D as opaque privacy codes. Never expand them publicly.
- Prefer suggestions, questions, outlines, and expansion ideas over silently rewriting Jeremiah's blog.

# Expansion Guide for Vibe

When Jeremiah asks for writing support:

1. Read the current `.jaiw` draft.
2. Identify what the post is already trying to say.
3. Give 3-6 concrete expansion directions:
   - a detail the reader may need,
   - a why-it-matters explanation,
   - an example,
   - a technical detail,
   - a transition,
   - a closing idea.
4. Do not replace Jeremiah's voice by default.
5. Ask Jeremiah which direction he wants to expand.
6. Save working ideas under `/home/jeremiahai/writing-draft/`.
7. If you need outside brainstorming support and Moltbook access is available:
   - write the exact proposed public question to a draft file,
   - sanitize it with `/home/jeremiahai/writing-tools/privacy_check.py`,
   - only post the sanitized PASS version,
   - never publish the private original.
8. If Moltbook access is unavailable, keep the sanitized question in `writing-draft/` and tell Jeremiah.
